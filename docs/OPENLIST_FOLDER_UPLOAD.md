# OpenList 式文件夹上传与浏览说明

## 目标

上传页改为“上传工作区”：不再用单独的“选择多个文件 / 选择文件夹”大入口，而是以目录树为主。用户先在目录树中进入目标位置，再在当前目录上传文件或文件夹，上传前可以继续整理目录结构、勾选要提交的文件并预览。

详情页按上传时保存的 `relative_path` 还原目录结构，用户可以像 OpenList 一样进入子目录，选择文件后在详情页内嵌预览。

## 前端上传行为

- 上传页左侧为目录树，中间为当前目录内容，右侧为上传前预览。
- 在当前目录点击“上传文件”时，选择的文件会追加到该目录。
- 在当前目录点击“上传文件夹”时，浏览器会读取文件夹内所有文件，并保留文件夹内部相对路径后追加到该目录。
- 新增文件不会覆盖原工作区内容，用户可以分多次继续添加文件。
- 已有同路径文件时，新追加或移动的文件会自动生成 `文件名 (1).扩展名` 形式，避免覆盖。
- 上传前可以在目录树中创建、删除、重命名、移动文件夹，也可以删除、重命名、移动文件。
- 移动文件或文件夹时，通过弹窗目录树选择目标目录；文件夹不能移动到自身或子目录。
- 文件重命名时，如果同目录存在同名文件，会提示并拒绝。
- 文件夹重命名或移动时，如果目标位置存在同名文件夹，会提示并拒绝。
- 上传时只提交已勾选文件，未勾选文件只保留在本地工作区。
- 图片、PDF、视频、音频、文本支持上传前预览。
- DOCX/PPTX 上传前提示上传后可在详情页用浏览器端 JS 预览。
- 不在预览白名单内的文件类型会标记为“仅上传”，不会尝试本地预览，但仍可正常上传和删除。

## 断点存储

- 上传工作区草稿保存在浏览器 IndexedDB 中，数据库名为 `learning-resource-upload-workspace`。
- 草稿包含表单、待上传 `File` 对象、虚拟文件夹、勾选状态、当前目录和当前预览文件。
- 页面刷新或重新进入上传页后，会自动恢复草稿，用户可以继续追加文件，不需要重新选择已有文件。
- 点击“清空工作区”会删除 IndexedDB 草稿。
- 草稿只保存在当前浏览器本地；清理浏览器站点数据、换浏览器或换设备后不会保留。
- 大文件会占用浏览器本地存储空间，课程视频较多时建议分批提交。

## 详情页行为

- 文件夹详情页通过 `GET /api/resources/{id}/children` 获取子文件。
- 前端使用每个子文件的 `relativePath` 生成目录树。
- 上方展示目录树和当前目录内容，下方以正常页面宽度预览选中的文件。
- 不在预览白名单内的文件类型会标记为“仅下载”，不会尝试在线预览，但仍可下载和删除。
- 删除按钮只在当前登录用户是资源上传者或管理员时显示。

## 已上传文件夹编辑

- 文件夹上传者或管理员在详情页可以点击“编辑文件夹”进入编辑模式。
- 编辑模式支持在当前目录追加文件，或追加文件夹内全部文件。
- 编辑模式支持重命名、移动、删除文件。
- 编辑模式支持重命名、移动、删除逻辑文件夹；逻辑文件夹通过批量改写其下文件的 `relativePath` 实现。
- 移动文件或逻辑文件夹时，通过弹窗目录树选择目标目录。
- 追加或移动时如出现同路径文件，后端会自动追加 `(1)` 后缀，避免覆盖已有文件。
- 当前版本不单独持久化空文件夹；逻辑文件夹需要至少包含一个文件才会在详情页目录树中显示。

## 后端行为

- 单文件上传仍使用 `POST /api/resources`。
- 多文件上传使用 `POST /api/resources/batch`，前端传入 `files` 和对应的 `relativePaths`。
- 已上传文件夹追加文件使用 `POST /api/resources/{id}/children`。
- 已上传子文件重命名或移动使用 `PUT /api/resources/{id}/file-path`。
- 已上传逻辑文件夹重命名或移动使用 `PUT /api/resources/{id}/folder-path`。
- 删除接口仍使用 `DELETE /api/resources/{id}`。
- `ResourceService.assertOwnerOrAdmin` 负责校验资源上传者或管理员权限。
- 删除文件夹时会软删除其子文件。
- 删除子文件时会刷新父文件夹的 `file_count` 和 `file_size`。
